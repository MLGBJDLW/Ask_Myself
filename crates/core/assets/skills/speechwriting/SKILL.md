# Speechwriting

## Core Rule
Write for the ear, not the page. Optimize for audience memory, timing, breath, emphasis, and the speaker's natural voice.

## First Pass
1. Identify audience, occasion, goal, time budget, speaker role, and desired emotional shift.
2. Choose one speech arc:
   - Pitch: problem -> stakes -> insight -> solution -> proof -> ask.
   - Keynote: story -> tension -> idea -> evidence -> implication -> charge.
   - Briefing: context -> decision needed -> options -> recommendation -> next steps.
   - Ceremony/toast: relationship -> specific story -> meaning -> blessing/close.
3. Decide the one sentence the audience should remember.
4. Build the script in spoken units: short paragraphs, signposts, pauses, and concrete images.

## Drafting Rules
- Start with a hook that creates attention: story, contrast, question, stakes, or surprising fact.
- Keep sentences speakable; break long written sentences into breath groups.
- Use repetition deliberately: triads, callbacks, parallel clauses, and refrain lines.
- Prefer concrete verbs and nouns over abstract claims.
- Put numbers into human scale.
- End with a clear close: decision, commitment, invitation, or image.

## Delivery Layer
Include delivery notes only when they improve performance:
- `[pause]` for silence that carries meaning.
- `[slow]` for dense or emotional lines.
- `[look up]` for audience connection.
- `[click]` when synced with slides.

## Review Checklist
- Can the speech goal be named in one sentence?
- Does every section move the audience closer to that goal?
- Is there a memorable line before the midpoint and at the close?
- Are claims supported by proof, story, or authority?
- Does the ending tell listeners what to think, feel, or do next?

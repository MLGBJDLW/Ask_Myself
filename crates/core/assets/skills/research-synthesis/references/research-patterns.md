# Research Patterns

## Evidence Matrix
| Sub-question | Claim | Source | Evidence type | Confidence | Caveat |
|---|---|---|---|---|---|

## Current-Fact Check
Use for laws, prices, schedules, APIs, software versions, public roles, policies, product specs, and news.
1. Verify date and authority.
2. Prefer official docs or primary announcements.
3. Compare at least two sources when the first source is not primary.
4. State the exact date of the source or event when recency matters.

## Contradiction Handling
When sources disagree:
1. Name the disagreement.
2. Check whether dates, definitions, jurisdiction, or scope differ.
3. Prefer the source closest to the underlying event or governing authority.
4. If unresolved, present both claims and mark the answer uncertain.

## Literature Review Lite
1. Define inclusion criteria: domain, date range, source type, language, and quality bar.
2. Cluster findings by mechanism/theme, not by source order.
3. Track methods and limitations for each major source.
4. Distinguish consensus, emerging evidence, disputed claims, and gaps.

## Recommendation Structure

- [Concrete source or test]

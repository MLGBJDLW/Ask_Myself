# Fiction Quality Gate

Use this reference before finalizing substantial fiction work: a full chapter,
longform outline, continuation, imported-manuscript diagnosis, or prose rewrite.
Run only the gates relevant to the user's request; do not turn a quick answer
into a long report.

## Contents

- Gate Levels
- Planning Gate
- Chapter Gate
- Continuation Gate
- Chinese Prose Gate
- De-Generic Gate

## Gate Levels

- Light: quick scene, brainstorm, or small polish. Check only canon, usefulness,
  and the user's requested constraint.
- Standard: chapter plan, chapter draft, continuation, or critique. Check
  structure, reader promise, continuity, and prose risks.
- Strict: longform project setup, final chapter draft, imported manuscript, or
  user asks for professional quality. Check all relevant gates and repair before
  presenting.

## Planning Gate

For premises, outlines, chapter cards, and story bibles:

- Reader promise is explicit.
- Protagonist or focal relationship has pressure, not only biography.
- Opposition has agency or systemic force.
- Stakes are specific and become more concrete over time.
- Beats are causal: because/therefore, not just "and then."
- Payoffs are scheduled: what opens, advances, and closes.
- The first chapter has external pressure early.
- The ending direction answers the dramatic question or deliberately leaves a
  series hook.
- Longform projects have tracking surfaces: cast, world/canon, timeline,
  promises, and character state.

Repair if weak:

- Add a sharper central pressure.
- Convert passive lore into a decision or conflict.
- Add a visible progress ladder.
- Split vague "things escalate" into concrete reversals.

## Chapter Gate

For chapter or scene drafts:

- Opening disturbance appears early.
- POV, tense, naming, and voice match established canon.
- The POV character wants something in the unit.
- Resistance forces a tactic shift.
- At least one state changes: information, power, relationship, danger, status,
  resource, location, emotion, or commitment.
- The chapter delivers the named reader emotion.
- Dialogue changes pressure rather than only explaining.
- Description affects clueing, mood, class/status, danger, intimacy, or action.
- The ending hook is earned by the chapter and opens forward pressure.
- If a length target exists, verify with a tool when practical; do not estimate
  long chapter length by eye.

Repair if weak:

- Move conflict earlier.
- Add a mid-chapter reversal.
- Make a choice cost something.
- Replace explanatory emotion with behavior and consequence.
- Pay off one small promise before opening a new one.

## Continuation Gate

Before continuing from existing material:

- Last accepted ending has been read.
- Current open promises are known.
- Involved character states are known.
- Timeline and location are plausible.
- No major canon invention is silent.
- New chapter preserves established POV, tense, naming, and paragraph rhythm.
- Any changed state is recorded after drafting if working in files.

If context is missing and invention would change canon, ask one focused question.
If the gap is small, make a labeled assumption and continue.

## Chinese Prose Gate

For Chinese-language fiction or translated Chinese-style output:

- Register matches the setting and narrator.
- Paragraphs suit mobile reading and tension level.
- Dialogue sounds partial, strategic, and character-specific.
- Emotional claims are supported by behavior, object, action, silence, or choice.
- The prose avoids translated English cadence: excessive abstract connectors,
  symmetrical over-polished phrasing, repeated "realized/felt/understood" moves,
  and generic emotional labels.
- Terms of address, hierarchy, relationship language, and genre vocabulary are
  consistent.

Repair if weak:

- Add concrete scene objects and physical reactions.
- Break long paragraphs at pressure shifts.
- Give each speaker a different tactic.
- Replace generic summary with a visible action.

## De-Generic Gate

Use when prose feels AI-smooth, interchangeable, or over-explained:

- Does every paragraph do a new job?
- Are there repeated sentence patterns or abstract transitions?
- Could this scene happen only in this story?
- Does each important character react differently?
- Is there subtext, silence, wrong inference, or asymmetry?
- Are details functional rather than decorative?

Repair with:

- Specific nouns and verbs.
- Imperfect dialogue.
- Behavioral contradiction.
- Scene-specific objects.
- Uncomfortable pauses or avoidance.
- Consequences that remain after the scene ends.

## Revision Gate

For critique or rewrite:

- Diagnose the highest-leverage issue first.
- Separate macro fixes from line edits.
- Preserve user voice unless asked to transform it.
- Mark any added, removed, or changed canon.
- Do not hide structural changes inside a polish pass.
- Provide clean revised text when the user asked for usable prose.

## Output Policy

- If the user asked for prose, deliver prose first and keep notes short.
- If the user asked for critique, lead with findings and concrete repairs.
- If the user asked for planning, provide structured artifacts, not craft lecture.
- If the user asked for autonomous longform work, report progress and files
  touched, then continue within the confirmed scope.
- Do not expose every gate result unless it helps the user act.
